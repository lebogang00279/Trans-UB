functional requirements

1.User registration and login-the system shall allow students to register and login using a
prototype account with student ID verification simulated using synthetic test data
Create and manage listings-the system shall allow sellers to create,edit and submit listings for
approved low risk physical goods

2.The system shall allow a seller to create and edit a listing for an approved low-risk physical good.

3.Listings approvals-The system shall allow the platform administrator to approve, reject or
remove listings before they are made available to buyers

4.Search and browser listings-The system shall allow buyers to search, browse, filter and
compare approved listings by criteria such as category, price and seller rating

5.Reserve or order an item-The system shall allow a buyer to reserve/order an available listing and
shall change the listing status to Reserved to prevent another buyer from ordering it
simultaneously

6.Accept or reject orders-the system shall allow the seller to accept or reject a pending order.If
rejected the system shall change the order status to Rejected and return the listing to Available

7.Reservation expiry and cancellation-The system shall automatically expire an order if the seller
does not respond within 24 hours and shall allow the buyer to cancel an order before physical
handover. In either case, the listing shall return to Available

8.Confirm transaction completion-The system shall allow the seller to mark an item as Delivered
and allow the buyer to confirm receipt, after which the order shall be changed to Completed

9.Seller ratings and reviews-The system shall allow only a buyer with a Completed order to
submit one review for that transaction and shall update the seller’s rating using completed
transaction reviews

10.Reporting and dispute handling-The system shall allow buyers and sellers to report a listing,
user or order and shall allow the platform administrator to review the report, record a resolution,
remove listings, suspend accounts or escalate serious unresolved disputes to the SRC
