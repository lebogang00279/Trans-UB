# TRANS-UB Lab 10 — Accessibility Checklist

- [ ] All controls are keyboard reachable.
- [ ] Visible focus indicator is present.
- [ ] Focus order follows task order.
- [ ] Inputs use persistent labels.
- [ ] Placeholder text is not the only label.
- [ ] Required fields are identified in text.
- [ ] Errors explain both problem and correction.
- [ ] Status meaning does not rely on colour alone.
- [ ] Available / Reserved / Pending / Completed are shown as text.
- [ ] Text remains readable on phone-sized screens.
- [ ] Core task does not require horizontal scrolling.
- [ ] Touch targets have adequate size/spacing.
- [ ] Reserve is clearly different from payment.
- [ ] Reservation terms show 24-hour seller response.
- [ ] Success shows Order = Pending and Listing = Reserved.
- [ ] Stale/unavailable state explicitly says no Order was created.
- [ ] Offline/unknown outcome tells user to check My Orders before retrying.
- [ ] Resolve and Escalate are clearly distinct administrator actions.
